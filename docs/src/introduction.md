# Loot Rules

- Whenever you receive a loot roll, you roll a d100 and gain the corresponding result.
- The result of any loot roll can be sold for 50 tokens, which can be used for improving your items via [shrines](reference/shrines.md). 
You can buy access to these shrines in towns.
- Whenever you upgrade your items via a shrine, its sell value increases by an amount equal to the shrine's cost,
so you retain your overall net worth if you want to swap out an item.
  - Note that shrine effects that aren't purely upgrades, like _Entropy_ or _Soul Transference_, won't increase the item's sell value.
- You can buy loot rolls in town for 100 gold.
