# Vestiges

- Vestiges grant a series of increasingly powerful mods with a certain focus.
- A character can equip an unlimited number of vestiges, but cannot equip multiple vestiges with the same type. 
By default, there are 11 different vestige types.
  - A _Shrine of Exaltation_ can be used to create custom vestige types. The focus of a vestige is not specific to a feature,
like a [rune's inspiration](runes.md), instead targeting a broad archetype.
Note that any choice of a new vestige type is subject to the GM's approval, and should not be too similar to existing vestige focuses.
- Vestiges you find begin at level 1, and you can use a _Shrine of Bestowing_ to level them up, up to level 5. 
Each level will grant a new modifier, with later modifiers typically being more impactful than the earlier ones.
