# Missions

- Missions gained by a character can only be completed by that character, unless delegated with a _Shrine of Delegation_.
When delegating a mission, it is still yours: you still gain its reward, and the mission counts as belonging to you for
the purpose of anything that counts how many active missions you have.
- You can have an unlimited number of concurrent missions, including duplicate missions. 
If you have more than one mission of the same type, you only need to satisfy their condition once to complete all of them.
